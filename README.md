# مهارة نماذج جوجل للوكلاء (`gws-forms-win`)

مهارة ذكاء اصطناعي (Agent Skill) مبنية وفق معيار [agentskills.io](https://agentskills.io) لمختلف وكلاء البرمجة والأتمتة (نحو Claude Code وGemini CLI وAntigravity)، تُكسب الوكيل القدرة الكاملة على إنشاء نماذج واستبيانات واختبارات Google Forms وتعديلها وقراءة استجاباتها آلياً في بيئة Windows عبر أداة Google الرسمية (`@googleworkspace/cli`)، مع حصانة تامة ضد مشكلات الهروب الطرفي للمحارف الخاصة.

---

## كيف تعمل المهارة؟

تعمل المهارة وفق معمارية الإفصاح التدريجي (Progressive Disclosure) للمعيار المفتوح لمهارات الوكلاء:

1. **الكشف التلقائي (Discovery)**: يقرأ الوكيل ترويسة [SKILL.md](SKILL.md) عند استهلال جلسته لتعيين اختصاص المهارة ومحفزات استدعائها.
2. **التفعيل (Activation)**: متى طُلب من الوكيل بناء نموذج، أو إضافة أسئلة، أو تفعيل التصحيح الآلي، أو جلب ردود نموذج، يستدعي الوكيل موجه المهارة في نافذة سياقه.
3. **مطالعة المرجع (Reference Consultation)**: يستشير الوكيل المرجع التقني عالي الكثافة في [references/REFERENCE.md](references/REFERENCE.md) على نحو مستقل دون تشتيت متن المهارة؛ للتحقق من هياكل طلبات `batchUpdate` الخام، ومسارات `updateMask`، وشفرات الخطأ السحابية.
4. **التنفيذ المؤتمت (Execution)**: يحرر الوكيل ملف مواصفة مهيكل بصيغة JSON (`form.json` أو `update.json`)، ثم يفوّض سكربتات بايثون التنفيذية للاتصال بواجهة برمجة التطبيقات محلياً عبر `node.exe` مباشرة.

## التثبيت والاستخدام

تتوافق المهارة مع وكلاء الذكاء الاصطناعي بنسخ مجلد المهارة مباشرة إلى مسار المهارات المستهدف:

### 1. على مستوى المشروع (Project Level)
توضع المهارة في دليل مهارات مساحة العمل:
```text
.agents/skills/gws-forms-win/
# أو
.claude/skills/gws-forms-win/
```

### 2. على مستوى النظام العام (Global Level)
توضع المهارة في مسار المهارات العام في نظام التشغيل:
```text
~/.claude/skills/gws-forms-win/
# أو مسار مهارات الوكيل المعتمد في بيئتك
```

### متطلبات التشغيل الأساسية (Prerequisites)
تتطلب المهارة تثبيت أداة Google Workspace CLI وتسجيل الدخول مرة واحدة:
```powershell
npm i -g @googleworkspace/cli
cmd /c "gws auth login"
```

## المنهجية والميزات الحاكمة

- **منهجية JSON-First**: يكتب الوكيل مواصفة النموذج في ملف JSON مقتضب وبديهي، وتتولى السكربتات التنفيذية كافة تفاصيل التحويل والتحقق والاتصال.
- **تغطية شاملة لـ 11 نمطاً**: دعم كامل لكافة عناصر Google Forms API v1:
  - الأقسام والنصوص: `section` (فاصل قسم)، `text` (نص إيضاحي).
  - الأسئلة النصية والموضوعية: `short` (إجابة قصيرة/فقرة)، `mcq` (اختيار متعدد / مربعات اختيار / قوائم).
  - المقاييس والتقييم: `scale` (مقياس خطي)، `rating` (تقييم بالنجوم أو القلوب)، `time` (وقت أو مدة)، `date` (تاريخ وسنة ووقت).
  - المصفوفات والشبكات: `grid` (شبكة أسئلة متعددة الصفوف والأعمدة).
  - الوسائط المتعددة: `image` (صور مباشرة مع نص بديل)، `video` (مقاطع YouTube مع تحكم في الأبعاد والمحاذاة).
- **نظام التصحيح الآلي (Auto-Grading & Feedback)**: توليد درجات الأسئلة وتحديد الإجابات الصحيحة وربط التغذية الراجعة المزدوجة (للصواب والخطأ) فورياً عند تفعيل خيار `quiz: true`.
- **منع انزياح المراجعات (Zero Revision Drift)**: تحديث تلقائي وذري للقطة النموذج (`snapshot`) عقب كل عملية تعديل لحماية العمليات التتابعية من تعارضات `revisionId`.
- **حصانة الهروب الطرفي (Direct Node Invocation)**: استدعاء `node.exe` مع `run.js` مباشرة، لتجاوز مشكلات تداخل محارف PowerShell وcmd مع الرموز العربية، والاقتباسات، والشرطات الطويلة (`—`).
- **تطبيع كامل للاستجابات (Paginated Response Reader)**: استخراج كافة ردود الطلاب والمستجيبين وتطبيع درجاتهم وأسمائهم مع دعم ترشيد النطاق الزمني والتصفح التلقائي للصفحات.

## بنية المهارة ومكوناتها

```text
gws-forms-win/
├── SKILL.md                     # موجه النظام الحاكم ودليل سير العمل
├── README.md                    # دليل المهارة ومعماريتها وبيانات التثبيت
├── references/
│   └── REFERENCE.md             # المرجع الفني الشامل لمواصفة Google Forms API v1
├── scripts/
│   ├── form_builder.py          # مكتبة بناء الطلبات والاتصال بـ gws
│   ├── json_runner.py           # سكربت إنشاء النماذج من مواصفة JSON
│   ├── form_fetcher.py          # سكربت جلب النماذج وبناء اللقطات السريعة
│   ├── form_updater.py          # سكربت تنفيذ التعديلات التراكمية على النماذج
│   └── form_reader.py           # سكربت استخراج الاستجابات وتطبيع الدرجات
└── tests/
    ├── run_tests.py             # جناح اختبارات الوحدات المؤتمت (15 اختباراً)
    ├── simulate_lifecycle.py    # محاكي دورة العمل الشاملة بمراحلها الـ 4
    ├── comprehensive_form.json  # مواصفة الاستمارة الشاملة بكافة الأنماط الـ 11
    └── comprehensive_update.json # مواصفة حزمة التحديثات الشاملة لكافة العمليات
```
