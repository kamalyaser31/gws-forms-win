# مهارة نماذج جوجل للوكلاء (`gws-forms-win`)

مهارةُ وكيلٍ (Agent Skill) على مواصفة [agentskills.io](https://agentskills.io)، يُنشئ بها الوكيلُ نماذجَ Google Forms واستبياناتها واختباراتها، ويعدّلها، ويقرأ ردودها، على Windows بأداة Google الرسمية `@googleworkspace/cli`. وتعمل مع كل وكيل يقرأ مهارات هذه المواصفة، كـ Claude Code وGemini CLI وAntigravity.

---

## كيف تعمل المهارة

تجري المهارة على الإفصاح التدريجي (Progressive Disclosure)، فلا يحمل الوكيل منها إلا ما يحتاج إليه في كل مرحلة:

1. **الاكتشاف (Discovery):** يقرأ الوكيل في بدء جلسته اسمَ المهارة ووصفَها من ترويسة [SKILL.md](SKILL.md)، ولا شيء غيرهما.
2. **التفعيل (Activation):** متى طُلب منه إنشاءُ نموذج، أو إضافةُ أسئلة، أو تصحيحٌ آلي، أو جلبُ ردود، حمّل متن `SKILL.md`.
3. **المعايرة (Calibration):** يرجع إلى [references/REFERENCE.md](references/REFERENCE.md) عند الحاجة وحدها، ليتثبّت من هياكل طلبات `batchUpdate` الخام، ومسارات `updateMask`، ورموز الأخطاء.
4. **التنفيذ (Execution):** يكتب ملف مواصفة بصيغة JSON (`form.json` للإنشاء، و`update.json` للتعديل)، ثم يشغّل السكربت المقابل له.

---

## التثبيت

يُنسخ مجلد المهارة كاملاً إلى مسار مهارات الوكيل:

- **لمشروع واحد:** `.agents/skills/gws-forms-win/` أو `.claude/skills/gws-forms-win/` داخل المشروع.
- **لكل المشاريع:** `~/.claude/skills/gws-forms-win/`، أو مسار المهارات العام لوكيلك.

### المتطلبات

- Python 3.10 فما فوقه، وNode.js.
- أداة Google Workspace CLI، مع تسجيل الدخول مرة واحدة:

```powershell
npm i -g @googleworkspace/cli
cmd /c "gws auth login"
```

## الاستعمال

يُطلب من الوكيل ما يُراد بلغة عادية، وهو يتولى الباقي. فإذا قلت له: «أنشئ اختباراً من ثلاثة أسئلة اختيار في أركان الصلاة، لكل سؤال درجتان»، كتب `form.json` بالأسئلة والإجابات الصحيحة، ثم شغّل:

```powershell
python scripts/json_runner.py form.json
```

فيطبع رابطَ التحرير ورابطَ المستجيبين. ولتعديل نموذج قائم أو قراءة ردوده سكربتات أخرى، شرحُها وصيغُ ملفاتها في [SKILL.md](SKILL.md).

## الإعداد

لا يلزم إعدادٌ في الغالب: تجد السكربتاتُ `run.js` بجوار أمر `gws` في مسار PATH، فتعمل مع `nvm` ومع بادئات npm المخصصة. فإن لم تجده، فلك أن تحدّد المسارين بمتغيري بيئة:

| المتغير | ما يحدّده |
|---|---|
| `GWS_FORMS_GWS_JS` | مسار `run.js` في الحزمة `@googleworkspace/cli` |
| `GWS_FORMS_NODE_EXE` | مسار `node.exe` |

## الميزات

- **الإنشاء من ملف JSON مقتضب:** يكتب الوكيل المواصفة وحدها، والسكربتات تتولى التحويل والتحقق والاتصال.
- **أحد عشر نوعاً من العناصر:**
  - الأقسام والنصوص: `section` و`text`.
  - الأسئلة: `short` (إجابة قصيرة أو فقرة)، و`mcq` (اختيار واحد، أو مربعات اختيار، أو قائمة منسدلة).
  - المقاييس: `scale` و`rating` و`date` و`time`.
  - الشبكات: `grid`.
  - الوسائط: `image` بنص بديل، و`video` من YouTube.
- **التصحيح الآلي:** درجةٌ لكل سؤال، وإجابةٌ صحيحة أو أكثر لأسئلة المربعات، وتعقيبٌ على الصواب وآخرُ على الخطأ، متى ضُبط `"quiz": true`.
- **الفحص قبل الإنشاء:** تُفحص المواصفة قبل أن يُنشأ شيء، فالنوع المجهول، والمفتاح الناقص، والإجابة الصحيحة التي ليست من الخيارات، كلها توقف التشغيل برسالة واضحة، ولا يُترك نموذج فارغ في Drive. وإن أُنشئ النموذج ثم أخفقت إضافة أسئلته، ذُكر رابطه في رسالة الخطأ.
- **النماذج الكبيرة:** تُرسل الأسئلة في دفعات متتابعة، لأن Windows يحدّ سطر الأوامر الواحد بـ 32,767 حرفاً.
- **التعديل الآمن:** تُحدَّث لقطة النموذج (`snapshot`) بعد كل عملية، فلا تتعارض العمليات المتتابعة في `revisionId`. وإن طُبّقت العملية وأخفق تحديث اللقطة، عُدّت العملية ناجحة مع تنبيه، فلا تُكرَّر.
- **قراءة الردود:** تُجلب الردود كلها صفحةً بعد صفحة، بدرجاتها وبريد أصحابها، ومع كل إجابة عنوانُ سؤالها، ويجوز قصرها على ما بعد تاريخ معيّن.
- **لا هروب للمحارف:** يُستدعى `node.exe` مع `run.js` مباشرة دون PowerShell ولا cmd، فلا تفسد العربيةُ ولا علاماتُ التنصيص ولا الشرطاتُ الطويلة (`—`) نصَّ الطلب. وتُقبل ملفات JSON بعلامة BOM ودونها.

## المساهمة

يُرحَّب بالمساهمة:

- **بلاغات الخلل (Issues):** لخطأ في سكربت، أو سلوكٍ يخالف ما في `SKILL.md`. ويُرفق بالبلاغ ملفُّ المواصفة ورسالةُ الخطأ.
- **طلبات الدمج (Pull Requests):** لنوع عنصر جديد، أو عملية تعديل جديدة. ويُرفق بكل تغيير اختبارٌ في `tests/run_tests.py`، ويُحدَّث `SKILL.md` إن تغيّرت صيغة المواصفة.

```powershell
python -m ruff check --fix scripts tests
python -m black scripts tests
python -m flake8 --max-line-length 88 scripts tests
```

وسجل التغييرات في [CHANGELOG.md](CHANGELOG.md).
